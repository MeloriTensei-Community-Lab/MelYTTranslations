# MeloriTensei's Video Translation Hub
### Translations repo for MeloriTensei's YouTube Channel
![Main readme banner](https://github.com/user-attachments/assets/e0434579-f528-4d3f-88f3-6c67993f32da)
Welcome to the GitHub repo where Mel hosts her subtitles, titles and descriptions in hopes to further ease the process for volunteer translators.


# Guide to contributing
**Step 1:** Check in the appropriate folders if there is an existing translation.
**Step 2:** Grab your favorite subtitling suite ([Subtitle Edit](https://github.com/SubtitleEdit/subtitleedit) and [Aegisub](https://aegisub.org/) are good options if you're someone just starting out but anything works!).
**Step 3:** Translate any video(s) that you would like and export it (or them) in accordance to the [Contributors Guidelines](#contributors-guidelines) section.
**Step 4:** Fork this repo.
**Step 5:** Once you're done with translating a video, create a pull request on the main repo, be sure to add a short description to your request.
**Step 6:** Wait for it to be approved. Be sure to respond to comments if there are any while waiting.
**Step 7:** PROFIT!!! Your translation will be shipped to the channel!

# Contributors Guidelines
This section serves the purpose to keep the subtitles quality to a certain standard.

Encoding: `UTF-8` (To ensure there are no unreadable characters down the line)
Format: SubStation Alpha (ASS) is encouraged, but other formats available (Refer to YouTube Help [here](https://support.google.com/youtube/answer/2734698 "here").)

Tone and Formalities: Follow as accurately as possible to the equivalent in your language.
Names: Melori Valentine/MeloriTensei (English), バレンタイン メロリ／転性メロリ（日本語）, 甘乐/転性女子 （中文）

------------


#### Rule 1: Neatly space sentences 
There are not exact character limits due to the way subs are rendered on the YouTube Player ([Reference: Reddit](https://www.reddit.com/r/youtube/comments/3peq4x/maximum_character_length_for_subtitles/ "Reference: Reddit")).

#### Rule 2: Only push when you're fully done with each video.
To keep the PR space clutter-free.

#### Rule 3: Be respectful of other contributors.
It is encouraged for translators of the same language to come together and solve conflicts relating to the project(s) if they arise. Disagree with something? Point out the flaw(s) in a comment on the pull request or Issues ticket! (or even in my Discord server's Translators channel)

#### Rule 4: Be coherent in the grammar and flow of the sentences.
When translating, translate the entire sentence and make sure that the final product interconnects for the best reading experience.

#### Rule 5: Sound effects are occasionally missed out in some videos (due to time constraints during subbing of the original video).
Just translate accordingly whether there are SFX or not. PRs to adding missing sound effects to the original subtitles are also welcome.

#### Rule 6: Fully LLM driven translations are NOT WELCOME.
You may use LLMs to help you jog your memory on one-two words you might have forgotten but translations mainly driven by LLMs are absolutely not welcome. The hallucinations and inconsistency of AI models will ruin the accuracy of what's said in the subtitles.
